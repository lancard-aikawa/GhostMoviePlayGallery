7-Zip —— パスワード付き zip は、ファイル名を隠さない

機密ファイル 4 つを、いちばん強い AES-256 のパスワード付き zip にする。ところが出来た書庫を開くとパスワードを訊かれず、中のファイル名が全部読める。zip はファイル名の一覧を暗号化しない仕様で、暗号の強さとは関係が無いと説明し、7z 形式の「ファイル名を暗号化」で隠せるところまで。

尺
約 69 秒
収録対象
7-Zip File Manager（winget install 7zip.7zip。撮影用のダミーは仕込みが作り、後片付けで消える）
素材
docs/video/assist-7zip/
設定
assist-7zip.zip（10 KB / 3 ファイル / 出所 365fc6b）
構成・台本・仕込みの一式。生成物は入っていません。どこに置いても動きます —— app.cwd はこのフォルダ自身で、仕込みが撮影用のダミーを作ります（C:\gmp\sample。後片付けで消えます）。
開いたらまず app.setup / app.start を読んでください（あなたの機械で走るコマンドです）。手引き → README_BUNDLE.md
再現
uv run gmp build docs/video/assist-7zip/plan.json --voice（Windows のみ。7-Zip が要ります）
機械が 7-Zip を操作して撮ります。 UI Automation にはウィンドウの枠しか出さないアプリですが、Win32 のウィンドウツリーからは一覧もダイアログも掴めるので、一覧の行をrow=給与明細_2026-07.pdf のように名前で指して操作しています —— 同じ台本から 2 回撮って9 枚のショットが byte 一致します。撮っている間はマウスとキーボードに触らないでください（本物の入力を送るので、前に出たウィンドウに入ります）。
